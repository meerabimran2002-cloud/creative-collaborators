# Creative Collaborators

Prompt for Lovable AI

Create a modern, premium, fully responsive collaboration portfolio website with 4 pages. The website should have smooth animations, glassmorphism effects, hover effects, modern cards, rounded corners, beautiful gradients, and a clean UI. Every button, project card, email, and LinkedIn link should be fully clickable.

Overall Design

- Modern, premium UI
- Responsive on Mobile, Tablet, and Desktop
- Smooth scrolling animations
- Fade-in sections
- Glassmorphism cards
- Gradient backgrounds
- Rounded buttons
- Professional typography
- Soft shadows
- Modern icons
- Open every project and LinkedIn link in a new browser tab
- Email should open the user's email app ("mailto:")
